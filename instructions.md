# Learning Trail - User Guide

A browser-based app to support early reading, phonemic awareness, and comprehension for young children (ages 4-6).

## Quick Start

```bash
npm install
npm run dev
```

Open the URL shown in your terminal (usually http://localhost:5173).

---

## Two Learning Modules

The app has two main areas:

| Module | Focus | Activities |
|--------|-------|------------|
| **Reading Trail** | Reading comprehension | Read stories, retell, answer questions |
| **Hyrule Field Guide** | Phonics + Reading | Sound counting, reading about creatures & items |

# Reading Trail

## For Children

### Reading a Story

1. **Choose a Story** - Tap any card on the main screen to pick a story
2. **Read or Listen** - Read the story yourself, or tap "Read to Me" to hear it aloud
3. **Read Again** - Tap "Read It Again" as many times as you want
4. **When Ready** - Tap "I'm Ready!" to continue

### Retelling the Story

After reading, you'll help retell the story by picking:
- **Who** is in the story
- **Where** it happens
- **What happened** - beginning, middle, and end

Watch your story summary build as you make selections!

### Answering Questions

- Tap the answer you think is correct
- You'll see right away if you got it right
- If you need help, you can go back and read the story again
- Keep going until you finish all questions

### Celebration!

When you're done, you'll see:
- How many questions you got right
- Stars for completing the story
- Your total stories read

### Progress Trail

On the main screen, you'll see circles for each story:
- **Gray circle (○)** - Not read yet
- **Gold star (⭐)** - Completed!

# Hyrule Field Guide

A collectible encyclopedia themed around The Legend of Zelda. Children unlock entries by completing two types of quests.

## How It Works

Each entry (creature, item, or character) starts **locked**. To fully unlock it:

1. **Sound Quest** → Unlocks the image
2. **Reading Quest** → Fully unlocks the entry

### The Collection View

- Locked entries show a "?" silhouette
- Entries with image unlocked show the picture but are grayed out
- Fully unlocked entries are bright and colorful
- Tap any entry to see details or start a quest

## Sound Quest (Phoneme Counting)

Sound Quest teaches **phonemic awareness** - the ability to hear individual sounds in words.

### How to Play

1. See a word displayed (e.g., "pig")
2. Tap "Hear it again" to listen to the word
3. Count the **sounds** you hear (not letters!)
4. Tap one rupee (diamond) for each sound
5. Tap "Check" to see if you're right
6. Complete all 4 words to unlock the image!

### Important: Sounds vs Letters

| Word | Letters | Sounds | Why |
|------|---------|--------|-----|
| pig | 3 | 3 | p-i-g |
| chest | 5 | 4 | ch-e-s-t (ch is one sound) |
| knight | 6 | 3 | n-igh-t (silent k, igh is one sound) |
| fish | 4 | 3 | f-i-sh (sh is one sound) |

Digraphs (ch, sh, th, wh, ng, ck) count as ONE sound because they make one sound together.

### If You Get It Wrong

- The game says "Let's try again!"
- Listen to the word one more time
- Count more carefully
- You can retry as many times as needed

## Reading Quest (Comprehension)

After unlocking the image, complete Reading Quest to fully unlock the entry.

### The Flow

1. **Read** - Read about the creature/item (tap "Read to Me" to hear it)
2. **Retell** - Answer "What is it?", "Where is it?", "What does it do?"
3. **Questions** - Answer 4 comprehension questions
4. **Celebrate** - See your unlocked entry!

### Question Types

- **Literal** - Find the answer directly in the passage
- **Vocabulary** - What does a word mean?
- **Inference** - Think about what the passage suggests

# For Parents

## Accessing the Parent Panel

1. Tap "Parent" in the top-right corner
2. Enter the magic word: **dragon**
3. You're in!

## What You'll See

### Reading Trail Progress
- Total stories completed
- Percentage of questions answered correctly
- Last reading date
- Recent activity log showing each completed passage and score

### Field Guide Progress
- Entries unlocked / total entries
- Images discovered / total entries
- Last activity date
- Sound Quest accuracy (phoneme counting)
- Reading Quest accuracy (comprehension questions)

## Adding Custom Passages

1. Go to "Add New Passage"
2. Enter a title
3. Type or paste the passage text (2-5 sentences work best)
4. Select type: Story (fiction) or Facts (informational)
5. Select reading level: Emergent, Early, or Developing
6. Tap "Add Passage"

Note: Custom passages won't have comprehension questions - they're for read-aloud practice.

## Managing Data

- **Delete custom passages** - Find them under "Your Custom Passages" and tap Delete
- **Reset Reading Trail progress** - Use the red "Reset All Progress" button
- **Reset Field Guide progress** - Use the "Reset Field Guide Progress" button

# Question Types

Each story includes a mix of question types to build different comprehension skills:

## Literal Questions
- **What they test**: Direct recall from the text
- **Example**: "Who found the shell?"
- **Tip**: The answer is stated directly in the passage

## Vocabulary Questions
- **What they test**: Understanding word meanings in context
- **Example**: "What does 'cozy' mean?"
- **Tip**: Use the sentence around the word for clues

## Inference Questions
- **What they test**: Reading between the lines
- **Example**: "How do you think she felt?"
- **Tip**: Think about what the story suggests, not just what it says

# Teaching Tips for Parents

## General Principles

1. **No pressure** - Let your child set the pace
2. **Read together** - Use "Read to Me" and follow along with your finger
3. **Celebrate effort** - Focus on participation, not just correct answers
4. **Re-read favorites** - Repetition builds confidence and fluency
5. **Add your own** - Use custom passages for topics your child loves

## For Sound Quest (Phonemic Awareness)

### What is Phonemic Awareness?
Phonemic awareness is the ability to hear, identify, and manipulate individual sounds (phonemes) in spoken words. It's a crucial pre-reading skill that predicts later reading success.

### How to Help

1. **Model sound stretching** - Say words slowly: "mmm-aaa-p" (map)
2. **Use your fingers** - Hold up one finger for each sound
3. **Tap it out** - Tap the table for each sound you hear
4. **Emphasize the tricky ones** - "Listen: 'fish' has /f/ /i/ /sh/ - that 'sh' is ONE sound!"

### Common Struggles

| Issue | What to Do |
|-------|------------|
| Counting letters instead of sounds | Cover the word, focus on listening |
| Missing digraphs | Practice: "Does 'sh' make one sound or two?" |
| Silent letters confusing them | "Some letters are quiet! We only count what we hear." |

### Practice Words by Sound Count

**3 sounds**: cat, dog, sun, map, fish, ship, bath
**4 sounds**: jump, club, chest, think, brand
**5 sounds**: stamp, trust, crisp, blast

## For Reading Quest (Comprehension)

### Before Reading
- Look at the picture together
- Ask: "What do you think this will be about?"
- Preview vocabulary words

### During Reading
- Pause and point to pictures
- Ask: "What just happened?"
- Make it interactive: "Oh no! What do you think will happen next?"

### After Reading
- Let them retell in their own words first
- Use the retell activity together
- For wrong answers, gently redirect: "Let's look at that part again..."

## Making It Fun

- **Celebrate unlocks** - Make a big deal when they unlock a new Field Guide entry
- **Create a routine** - Same time each day, maybe 10-15 minutes
- **Take breaks** - Stop while they're still enjoying it
- **Let them choose** - Which story? Which Field Guide entry?
- **Connect to life** - "Remember when we saw a bee? Let's read about bees!"

# Technical Notes

## Data Storage
- All data is stored locally in your browser (localStorage)
- Works offline after first load
- No account or internet required
- Data persists until you clear browser data or use reset buttons

## Text-to-Speech
- Uses your browser's built-in voice (Web Speech API)
- Speed is slowed down for young readers
- Works best in Chrome, Safari, Edge, and Firefox

## Images
- Field Guide images should be placed in `/public/images/field-guide/`
- Format: `{entry-id}.png` (e.g., `moblin.png`, `keese.png`)
- If images are missing, a placeholder gradient is shown

## Adding New Field Guide Entries

Edit `src/data/fieldGuideEntries.ts` to add entries. Each entry needs:

```typescript
{
  id: 'unique-id',
  name: 'Display Name',
  category: 'creature' | 'item' | 'character' | 'place',
  imageUrl: '/images/field-guide/unique-id.png',
  phonemeWords: [
    { word: 'word1', phonemes: ['w', 'or', 'd'] },
    // ... 3-4 words total
  ],
  passage: '3-5 simple sentences about the entry.',
  vocabulary: ['key', 'words'],
  retellElements: [
    { id: 'what', category: 'what', text: 'What it is', icon: '...' },
    { id: 'where', category: 'where', text: 'Where found', icon: '...' },
    { id: 'does', category: 'does', text: 'What it does', icon: '...' },
  ],
  comprehensionQuestions: [
    // 4 questions with choices and feedback
  ],
}
```

# Troubleshooting

| Problem | Solution |
|---------|----------|
| No sound on "Read to Me" | Check device volume; try a different browser |
| Progress not saving | Check if localStorage is enabled; not in private/incognito mode |
| Images not showing | Check that images exist in `/public/images/field-guide/` |
| App won't load | Run `npm install` then `npm run dev` |
